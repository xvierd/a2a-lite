# File Agent - A2A Lite (Java)

File handling agent using the **real A2A Lite library**.

## Skills

- `analyze` - Get text statistics (word count, line count, char count)
- `convert_to_upper` - Convert text content to uppercase
- `generate_report` - Generate formatted reports in JSON, Markdown, or Text

## Running

```bash
./gradlew run
```

Server starts on port 8789.
